# Sum up 26 November's world news in one image

Entry for make.fun competition `news-image-20261126`.

One front-page image summing up Thursday 26 November 2026: 26 stories from
7 regions — the Cairo tanker fire, India marking the 18th anniversary of the
26/11 Mumbai attacks, Taiwan answering the US tariff plan, and 23 more,
each verified as reported on 26 November 2026.

`entry.png` (1024x1024, 111,676 bytes) is the image. `main.py` copies it
unchanged to `/output/entry.png`, deterministically, with no network access.

Run it with:

```sh
python3 main.py
```
